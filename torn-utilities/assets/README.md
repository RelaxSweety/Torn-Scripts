# TU logo master

The current DEV logo is `tu-logo-integrated-gold.png`: the selected Integrated Gold design with flare highlights removed. This file is the version-controlled source for the launcher, shared headers and War Organizer. The build embeds its exact bytes once and reuses that image throughout the application.

Do not regenerate, upscale or recompress this asset during a build. Change it only for an explicitly requested artwork update. Keep the compact launcher dimensions and image proportions. Historical SVG/WebP files are retained for previous releases.
