# War Organizer window navigation — DEV .104

TU 0.5.42.104-dev / War Organizer 0.3.18-dev fixes minimize and overlapping TU pages. Item Monitor remains 1.12.53-dev.

The War Organizer root was absent from the Manager's unified navigation/visibility list, and its inline flex display could override ordinary hidden styling. The root is now registered for shared hide/show, launcher visibility and restoration. Known flex display is explicitly switched off/on when hidden/shown, with a hidden CSS fallback. War Organizer opening invokes unified navigation so the previous TU window is hidden immediately. Its native header has Back and named Minimize controls; existing close still returns to the Manager and stops module resources.

Minimize preserves the organizer DOM, position, draft fields, local selections and running module state. The launcher restores that same panel. Back shows the previous TU Manager page; opening the still-active War Organizer card resumes the existing panel rather than leaving two pages visible or rebuilding drafts. The organizer retains its own drag/resize/header/logo handling, avoiding duplicate generic floating-window handlers. The underlying Torn page is not modified.
