# Torn Utilities

The new DEV application uses one complete userscript with 10 integrated tools. See [installation](INSTALLATION.md), [build documentation](all-in-one/README.md), and [manual acceptance](all-in-one/docs/DEV-ACCEPTANCE.md).

The previous Manager and independent tool sources remain available for rollback and existing supported builds. The integrated DEV distribution does not fetch `modules.json` or install those sources separately. This branch does not promote changes to production.
