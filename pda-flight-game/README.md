# Torn PDA Flight Game

Mobile-first Torn PDA arcade game by RelaxSweety [4539436].

## Files

- `Torn-PDA-Flight-Game.user.js` — current release installed by Torn PDA
- `Torn-PDA-Flight-Game.meta.js` — lightweight version metadata for update checks
- `drafts/` — archived development versions

## Planned v0.2.0 changes

- Correct Torn flight route/status detection
- Continuous sliding touch/virtual joystick movement
- Smaller player aircraft and proportional hitbox
- Reduced control-panel height
- Torn PDA auto-update support

## Release process

Increment `@version`, update the release `.user.js`, update the `.meta.js`, and archive the prior release in `drafts/`.
